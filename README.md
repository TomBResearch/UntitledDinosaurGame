# Untitled Dinosaur Game

A browser-based 3D sandbox MMORPG set in prehistoric times. Start as a caveman with nothing but a pelt loincloth, then level up combat, gathering and crafting skills in a world full of dinosaurs.

- **Play (once live):** https://dinosaur.untitledgames.co.uk
- **Player wiki:** [`wiki/`](wiki/index.md)
- **Developer docs:** [`docs/`](docs/README.md)
- **Agents start here:** [`CLAUDE.md`](CLAUDE.md)

Built with Godot (client), Go (servers) and PostgreSQL, and part of the Untitled Games family, so one account works across all the games.
