## Task contract

### Objective and prerequisites

Establish a reproducible empty foundation and executable quality checks. Requires an authorised fresh checkout and P01 adoption. No game movement, engine or network behaviour belongs in this task. The implementing agent records exact runtime and tool versions, repository SHA and bootstrap commands before handoff.

### Owned files and outputs

Create the root files in [section 3.1](repository.md); docs/contracts/adoption.md; docs/integration/dependencies.json; docs/adr/0000-template.md; tools/checks/package.json; tools/checks/tsconfig.json; tools/checks/src/{boundaries,fixtures,evidence,run-contract}.ts; tests/contracts/UDG-001.test.ts; tests/fixtures/boundaries/{allowed,forbidden-client-server,forbidden-engine,cycle}/; and workspace package.json, tsconfig.json and src/index.ts skeletons for the five shared packages and two apps. Add tools/load-test only when Gate A needs it. Schema and engine dependencies may be selected here but implementation remains absent.

### Required work and public contract

Enable strict, noImplicitAny, noUncheckedIndexedAccess and exactOptionalPropertyTypes. Provide shared compiler settings with no DOM library in simulation, server, physics, navigation or protocol/domain. Client DOM types must not leak through ambient configuration. Export maps define domain versus schema entry points. Central scripts discover workspaces deterministically. dependencies.json records exact package versions, package manager version, Node version, lockfile SHA and source/licence references.

CI starts from a clean checkout, installs with the frozen lockfile and runs checks/builds. Missing secrets must not be required for a local run. Development services bind to loopback, use documented ports 2567 for server and 5173 for client and require explicit configuration for LAN exposure. The example environment contains no secrets. No deploy workflow is introduced.

### Tests and acceptance

Run the four root commands, pnpm test:boundaries and pnpm test:contract -- --task UDG-001. Verify an allowed dependency fixture passes and each forbidden edge/cycle fails for the expected reason. Verify an invalid TypeScript fixture fails strict checking, a runtime browser global in simulation is detected, a missing test suite fails rather than passes, and a modified lockfile is rejected by frozen install. Use disposable fixtures; do not break the main tree to demonstrate failure.

Pass only if a clean second installation leaves tracked files unchanged, every populated workspace checks/builds, CI reproduces the local result, boundary negatives are detected and README startup prerequisites are complete. Retain artifacts/RUN_ID/{environment.json,commands.json,junit.xml,boundary-report.json,build.log,report.json}. Failures in package/runtime selection block 002 and 004. Do not invent compatible versions to fill the report.
