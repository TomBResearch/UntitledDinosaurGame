# Task record templates

- [Assignment record](assignment.md): copy to `docs/contracts/assignments/TASK_ID.md` when the task is authorised. Pin the prerequisite commits and allowed paths.
- [Completion record](completion.md): attach to the final reviewed commit and evidence bundle. An implementer's recommendation does not verify a task.
- [ADR template](../../adr/0000-template.md): use for architecture conflicts and proposed deviations.

The original Word document's [assignment and completion templates](README.md) is represented by these files. No assignment or completion record has been approved by packaging this repository.
