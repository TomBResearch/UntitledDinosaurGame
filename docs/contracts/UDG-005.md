## Task contract

### Objective and prerequisites

Replace the flat spike rule with reusable locomotion and authority logic while retaining Gate A behaviour. Requires Verified Spike 001 and P05 adoption. This task consumes CharacterPhysics and NavigationService contracts through fakes; it does not import their engines. Preserve fixed dt, deterministic transitions and separate side-effect reporting.

### Owned files and interfaces

Create packages/simulation/src/{index,create-locomotion-simulator,step-locomotion,direct-intent,path-progress,movement-authority,route-store}.ts; tests/unit/simulation/{direct,path,authority,ownership}.test.ts; tests/contracts/UDG-005.test.ts; tests/fixtures/input/authority.json; and tests/reference/{FakeCharacterPhysics,FakeNavigationService}.ts. Replace the reference flat-step call sites in server/client adapters through networking-owner review, then rerun Gate A's direct fixtures.

Implement LocomotionSimulator, MovementAuthority and RouteStore from [canonical domain declarations](../interfaces/domain.md). Add factory binding as [section 4.1](../interfaces/domain.md). The authority holds session/identity context and exposes a separate readonly observation via getSnapshot(): PlayerSimulationState, plus takeResults(): readonly MovementCommandResult[] for adapter consumption after the tick. The v0.2 submit/advance methods keep their signatures. advance(T) supplies the current tick in the copied step state; assert that dt equals the configured fixed step. Do not derive server tick from client input.

The pure step validates mode/route consistency, normalises axes, calculates bounded desired displacement, integrates verticalVelocity, invokes collision once and returns StepResult without mutating its input state. The authority supplies an input-state copy with lastAuthorityTick set to T; the step preserves that value, so it needs no hidden clock. Missing route data in path mode returns idle/blocked safely. Route points are immutable; lookup is scoped. Proposed step faults throw a typed configuration/invariant error to the adapter before committing a new state; user input errors remain neutral/rejected outcomes. No partial canonical update survives a thrown step.

### Tests and acceptance

Run root checks, pnpm test:contract -- --task UDG-005 and the Gate A direct regression command for all seeds under LAN and elevated profiles. Test direct/diagonal 200-tick distance, zero and missing input, idle gravity, path segment clipping, multiple waypoints in one budget, arrival wrong floor, blocked counter, absent route, direct override, stale completion, new epoch and mutation resistance. O01-O12 are pure authority tests now, using explicit completion tickets and cutoff order.

Use two entity-bound simulators in one environment and assert that each CharacterPhysics call receives the correct entityId and route store. Compare replayed journals for exact same-runtime equality. Fail on non-finite state or invalid dt. Pass only if all required predicates hold, Gate A remains within thresholds and package-boundary checks show no engine/UI dependencies. Evidence includes locomotion-traces.jsonl, authority-permutations.json, bound-identity-calls.json and regression comparison to Gate A. Any signature change requires owner approval before dependent work proceeds.
