## Task contract

### Objective and prerequisites

Build repeatable greybox assets from one geometry source and prove authoritative Recast queries outside locomotion. Requires Verified Spike 002, adopted P08 and fixed collision/config hashes. This task owns asset and navigation formats; it must not import Babylon into the server or implement local predicted path following.

### Owned files

Create tools/asset-pipeline/{package.json,tsconfig.json}; src/{build-region,canonical-json,build-visual,build-collision,build-navmesh,verify-region}.ts; assets/source/region-greybox-001.geometry.json; assets/regions/region-greybox-001/{region.json,visual.glb,navmesh.bin,collision.json,manifest.json}; packages/navigation/src/{index,contracts,RecastNavigationService,NavigationWorker,validate-destination}.ts; apps/server/src/regions/load-region.ts; apps/client/src/game/verify-region.ts; tests/probes/recast-import-export.probe.ts; tests/contracts/UDG-007.test.ts; tests/fixtures/navigation/routes.json; tests/fixtures/assets/corruption.json; and docs/integration/navigation-format-v1.md.

### Manifest and format contract

manifest.json contains schemaVersion, regionId, sourceGeometryHash, navmeshHash, collisionHash, movementConfigHash and generatorVersion required by v0.2. P08 adds visualHash, regionHash, recastVersion, recastWasmHash, generatorSettingsHash, coordinateSystem with value RH_Y_UP_METRES and sourceFormatVersion. Hash values are SHA-256 of exact file bytes; source/config JSON uses canonical serialisation from 002. generatorVersion identifies the asset builder commit plus format version. manifestHash is the SHA-256 of canonical manifest bytes and is exchanged at join. The manifest does not contain its own hash.

region.json contains world/region IDs, axis convention, bounds and at least one validated spawn with position/yaw. collision.json contains schemaVersion and a sorted list of static meshes with stable IDs, finite baked vertices and valid triangle indices. Geometry transforms are baked once into shared source coordinates before GLB, collision and navmesh generation. visual.glb must retain the asymmetrical marker and source alignment. Validate triangle winding using known surface normals and an uphill/downhill fixture; a visual screenshot alone cannot prove collision/nav alignment.

### Navigation behaviour and bounded work

Use agent radius 0.35 m, height 1.8 m, climb 0.3 m and maximum slope 45 degrees; prove how generator settings map world units to any voxel units. Proposed initial voxel cell size is 0.10 m and cell height 0.05 m. Freeze actual erosion, region, contour and detail parameters with units after fixtures pass. Never erode for radius twice. Narrow-corridor fixtures use 0.60 m blocked and 1.00 m passable corridors, subject to measured skin/voxel clearance; uncertain boundary widths require documented validation, not a silent success.

Validate finite coordinates and 3D region bounds before query. Destination projection to navmesh may move at most 0.20 m horizontally and 0.20 m vertically; farther projection rejects INVALID_DESTINATION. Reject partial/truncated paths as UNREACHABLE even if the library reports a successful low-level operation. Cap accepted routes at 256 waypoints and queries at the chosen Detour node/polygon budget, initially 2048 visited nodes. Overflow cannot return an accepted truncated path.

Navigation has one pending query per entity and at most 32 queued jobs per room, with four new requests/second/entity and burst four. Excess returns RATE_LIMITED or NAVIGATION_BUSY without changing H. Use monotonic token replenishment; invalid request shape is rejected before expensive work. A worker executes queries outside the critical tick; elapsed deadline is 1000 ms. The worker wrapper must enforce a hard bounded native query budget and terminate/reinitialise a stuck worker after the deadline, with pending tickets rejected. Promise timeout alone does not stop a blocking native query and is insufficient.

### Tests and acceptance

Run root checks, pnpm assets:build -- --region region-greybox-001, pnpm assets:verify -- --region region-greybox-001 and pnpm test:contract -- --task UDG-007. Build twice in clean directories and compare hashes byte-for-byte, excluding no timestamps because outputs must contain none. Import/export the actual binary in Node and a browser probe and compare fixture query predicates. Verify R01-R10 and A01-A08. Corrupt each file/hash/config in isolation and assert startup/join rejection before admitting a player.

Traverse each accepted route with the Gate B capsule and collision world; all expected reachable routes must arrive without wall penetration beyond 0.02 m. Query CPU p95 must be below 20 ms on the declared runner over 1000 warmed queries, with memory/resource counts recorded and no queue exceeding its bound. Server startup on an invalid manifest fails closed; the browser displays a compatible-assets error. Evidence includes manifest/hashes, build comparison, generator settings, route polylines, traversal traces, query timing.csv and native resource counts. Geometry or serialization mismatch blocks Gate C.

**Exactly-once across an epoch change (GA-10a, GA-10b; deferred here from
[ADR-0003 §5](../adr/0003-input-acknowledgement-overflow-and-resynchronisation-policy.md)).** With the real
navigation intake and a validated route committed, measure the discrete-effect ledger on the accepted Gate A
harness plus real routes: `Δ == 1` for one route effect committed once; `Δ == 0` for an identity abandoned by
an epoch change; `Δ == 1` for the same request deliberately reissued under a new identity. The bundle is
replayable and names, per row, the epoch of each ledger key and the seat the effect belongs to. A run where
`pathCandidates == 0` cannot satisfy either row and must say so in the run record; a Gate A claim covering
successful navigation effects must cite evidence for both rows.

**Discrete queue limits (AC-3b, discrete half).** The same run reports `continuousHighWater` and
`discreteHighWater` for the 8-per-entity and 64-per-room discrete bounds. UDG-003 Phase 2 could not exercise
them because no discrete traffic exists — the retained maximum `discreteHighWater` across every Phase 2 room is
**0** — so the discrete half of the queue-limit evidence is outstanding here until this task supplies the
traffic.
