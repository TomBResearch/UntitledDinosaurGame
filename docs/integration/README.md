# Third party integration validation

- [Colyseus validation](colyseus.md): exact package/API probes, acknowledgement and prediction lifecycle, safe mode handoff.

- [Dependency register](dependencies.json): generated by `pnpm dependencies:record`; it is the ownership record for every pinned package.
- PR-13 overflow postures ([api map §9](colyseus-0.18-api-map.md)) and the decision document they feed: [ADR-P-0002, Proposed](../adr/proposals/UDG-003-compiler-exception-and-input-backlog-posture.md). It measures which public mechanism can prevent unrepresented acknowledgement (only matching consumption to the admitted rate, or an obeying sender: `clear()`, `seqField`, `sanitize()` and `drain()`-then-apply-latest cannot) and what a confined `skipLibCheck` exception would and would not still check. Both parts are proposals; nothing is adopted.
