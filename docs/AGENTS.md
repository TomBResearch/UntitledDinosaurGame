# Planning document maintenance

Read the [root instructions](../AGENTS.md). Maintain one operational owner per requirement and update dependent links when relocating content. Individual task files own task scope/paths/tests; shared interface files own common semantics; baseline text is immutable reference. Do not copy full shared policies into every task.

Record substantive changes through [adoption](contracts/adoption.md) and accepted [ADRs](adr/README.md). Publishing Markdown is not game implementation or a gate pass. Keep assignment, evidence and gate statuses truthful. Refresh `docs/contracts/checksums.json` when edition-controlled planning files change and record the new reviewed commit for approvals. Do not rewrite the preserved specification just to match a later implementation.
